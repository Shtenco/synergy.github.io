01 / ВОЗМОЖНОСТИ

Всё по задачам, а не по API-командам.

Отдельные модули с явными границами доступа и ответственностью за результат.

01 / MODULE

Каталог API и MCP

Индексирование объявленных возможностей и версий; поиск без загрузки тысяч инструментов в LLM.

02 / MODULE

OpenAPI Discovery

Нормализация методов, схем входа, документации и ограничений.

03 / MODULE

Tool Router

Сопоставление задачи с инструментом, проверка происхождения и доступных scopes.

04 / MODULE

Identity / Policy

Разрешения по пользователю и организации, approval, лимиты, журнал и отказ по умолчанию.

05 / MODULE

Execution Gateway

HTTPS allowlist, контролируемые методы и запрет произвольных внешних URL.

06 / MODULE

Workflow Engine

Сборка последовательностей действий с результатами и остановкой при ошибке.
