О Threads API

Threads API бесплатен, но требует прохождения App Review в Meta. Использует ту же авторизацию что и Instagram — Instagram Business аккаунт автоматически даёт доступ к Threads.
Возможности API:
  • Публикация текста (до 500 символов)
  • Публикация изображений (JPEG, PNG до 8MB)
  • Публикация видео (MP4, MOV до 5 минут, 1GB)
  • Карусели до 10 элементов
  • Ответы на посты (reply_to_id)
  • Аналитика: views, likes, replies, reposts, quotes
  • Cross-share в Instagram Stories (новинка 2026)

Подключение Threads

Сохраните access_token от Meta/Instagram. Токен должен иметь разрешения threads_basic и threads_content_publish.
Как получить: Используйте Instagram Graph API OAuth flow. Если у вас уже есть Instagram токен с нужными scopes — он подойдёт и для Threads.
POST /api/tool — tool: threads_save_token
POST /api/tool — tool: threads_check

Текстовый пост

Публикация текстового поста. Максимум 500 символов.
POST /api/tool — tool: threads_publish_text

Пост с изображением

Публикация поста с картинкой. Изображение должно быть доступно по публичному URL (JPEG или PNG, до 8MB).
POST /api/tool — tool: threads_publish_image

Пост с видео

Публикация видео. Видео должно быть доступно по публичному URL (MP4/MOV, до 5 минут, до 1GB). Обработка занимает время — сначала создаётся контейнер, затем публикуется.

Шаг 1: Создать контейнер

POST /api/tool — tool: threads_publish_video

Шаг 2: Опубликовать контейнер

POST /api/tool — tool: threads_publish_container

Ответ на пост

Ответить на существующий пост. Создаёт threaded conversation.
POST /api/tool — tool: threads_reply

Мои посты

Получить список своих постов в Threads.
POST /api/tool — tool: threads_get_posts

Аналитика поста

Получить метрики конкретного поста: views, likes, replies, reposts, quotes.
POST /api/tool — tool: threads_get_insights
