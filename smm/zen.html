SYNERGY / EDITORIAL DESK

Яндекс Дзен

Подготовка статей для Дзен в безопасном ручном режиме. Система сохраняет HTML- и JSON-черновик, который можно скачать и вставить в редактор Дзен. Недокументированный endpoint автопубликации не используется.

zen_check

Что это: Сохранение данных канала. Важно: система честно помечает их как сохранённые, но не как проверенные через публичный API, поскольку документированный endpoint автопубликации Дзен не подтверждён.
POST /api/tool — tool: zen_check
// Параметры
{ "token": "y0_...", "publisher_id": "...", "client_id": "...", "client_secret": "..." }

post_zen

Что это: Создание безопасного HTML- и JSON-черновика. Что получите: два файла для скачивания и ручной публикации в редакторе Дзен без ложного сообщения об успешной API-публикации.
POST /api/tool — tool: post_zen
Режим: manual_safe_export — HTML + JSON
// Параметры
{
"title": "Заголовок статьи",
"body": "Текст статьи..."
}

// Результат
zen_draft_YYYYMMDD_HHMMSS.html
zen_draft_YYYYMMDD_HHMMSS.json
