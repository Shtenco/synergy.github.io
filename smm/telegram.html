Telegram API

Полный набор методов Telegram из оригинальных файлов: backend_app.py (4 инструмента), TG COMBINE BOT (7 парсеров), main.py автопилот (3 инструмента), Telethon (7 API вызовов).

telegram_check (backend)

Что это: Инструмент для сохранения и проверки Telegram API ID и API Hash — ключей доступа к Telegram. Зачем нужен: Без этих данных ни один метод Telegram не будет работать. Это обязательный первый шаг перед запуском любых парсеров и инвайтеров. Что получите на выходе: Подтверждение, что API-ключи сохранены и валидны. Дальше можете запускать любой инструмент на странице.
POST /api/tool — tool: telegram_check

telegram_parse_groups (backend)

Что это: Инструмент, который ищет Telegram-группы по заданным ключевым словам через API и ставит задачу в очередь. Зачем нужен: Чтобы быстро собрать базу целевых групп по вашей тематике — например, группы по маркетингу, крипте, фитнесу. Что получите на выходе: Список найденных групп (названия, ссылки, участники). Можно использовать для последующего парсинга пользователей или приглашений.
POST /api/tool — tool: telegram_parse_groups

telegram_parse_users (backend)

Что это: Инструмент для поиска пользователей Telegram по ключевым словам. Задача ставится в очередь. Зачем нужен: Чтобы найти целевую аудиторию — людей, которые пишут или упоминают нужные вам темы в Telegram. Что получите на выходе: База пользователей с username, именем, ID. Можно использовать для массовых приглашений или аналитики.
POST /api/tool — tool: telegram_parse_users

telegram_invite (backend)

Что это: Инструмент подготовки массового приглашения пользователей в указанную Telegram-группу. Зачем нужен: Чтобы автоматически добавить собранных пользователей в вашу группу или канал. Что получите на выходе: Процесс приглашения пользователей из загруженного файла в целевую группу с обработкой лимитов и ошибок.
POST /api/tool — tool: telegram_invite

TG Bot Parser — Поиск людей

Что это: Парсер из TG COMBINE BOT, который ищет пользователей Telegram через глобальный поиск сообщений SearchGlobalRequest. Зачем нужен: Находит реальных людей, которые писали сообщения на интересующую вас тему — не просто аккаунты, а активную аудиторию. Что получите на выходе: .txt файл со ссылками на пользователей и .json с полными данными (id, имя, фамилия, username, телефон).
Telethon: SearchGlobalRequest(q, filter, min_date, max_date, limit) — поиск сообщений | client.get_entity(sender_id) — данные отправителя
// Процесс парсинга (TG Bot Parser.py — parsing_process):
1. client.connect() — подключение к MTProto
2. client.sign_in() — авторизация по коду
3. client(SearchGlobalRequest( keywords, InputMessagesFilterEmpty(), offset_id=0, limit=100 ))
4. Для каждого сообщения: client.get_entity(sender_id)
5. Сохранение: telegram_users_YYYYMMDD_HHMM.txt + .json

TG Bot Parser Group — Поиск групп

Что это: Инструмент поиска Telegram-групп по названиям через SearchGlobalRequest. Зачем нужен: Чтобы находить тематические группы для анализа аудитории или продвижения. Что получите на выходе: .txt файл со ссылками на группы и .json с данными о каждой группе.
Telethon: SearchGlobalRequest — поиск групп по названиям, сохранение .txt (https://t.me/... ссылки) и .json

TG Bot Parser Group 2 — Поиск групп с пагинацией

Что это: Улучшенная версия поиска групп с циклической пагинацией — собирает не одну страницу, а все доступные результаты. Зачем нужен: Обычный поиск выдает только первые 100 результатов. Пагинация позволяет собрать гораздо больше групп по вашему запросу. Что получите на выходе: Расширенный список групп (сотни и тысячи) с полными данными в .txt и .json.
Telethon: SearchGlobalRequest с offset_id, limit=100 — циклический поиск с пагинацией
// parsing_process с пагинацией:
offset_id = 0
while True:
  result = client(SearchGlobalRequest(..., offset_id=offset_id, limit=100))
  if not result.messages: break
  offset_id = result.messages[-1].id
  сохранение найденных групп

TG Bot Parser Group 3 — Поиск через диалоги

Что это: Альтернативный метод поиска — получает все диалоги аккаунта и ищет ключевые слова в сообщениях каждого чата. Зачем нужен: Если SearchGlobalRequest не даёт результатов или нужно искать внутри уже известных чатов и диалогов. Что получите на выходе: Список групп и сообщений, где найдены совпадения с ключевыми словами.
Telethon: GetDialogsRequest — получение диалогов | client.get_messages() — поиск в сообщениях чата

TG Bot Parser Users — Пользователи

Что это: Инструмент поиска пользователей через SearchGlobalRequest по ключевым словам из TG COMBINE BOT. Зачем нужен: Быстрый сбор аудитории по интересам — находит пользователей, которые упоминают нужные слова в своих сообщениях. Что получите на выходе: Список пользователей с username и контактными данными.
Telethon: SearchGlobalRequest + client.get_entity()

TG Bot Parser Human — Детальный парсер

Что это: Глубокий парсер, который выгружает абсолютно всех участников канала и все их сообщения. Зачем нужен: Для детального анализа аудитории канала — кто участники, о чём пишут, как часто активны. Что получите на выходе: Два .json файла — один со всеми участниками (id, имя, username, телефон), второй со всеми сообщениями (дата, текст, отправитель).
Telethon: dump_all_participants, dump_all_messages
// dump_all_participants(client, channel):
offset_user = 0; limit_user = 100
while True:
  participants = client(GetParticipantsRequest(channel, ChannelParticipantsSearch(''), offset_user, limit_user, hash=0))
  if not participants.users: break
  all_participants.extend(participants.users)
→ JSON: id, first_name, last_name, username, phone, is_bot

// dump_all_messages(client, channel):
offset_msg = 0; limit_msg = 100
while True:
  messages = client(GetHistoryRequest(channel, limit=limit_msg, offset_date=None, offset_id=offset_msg, ...))
  if not messages.messages: break
→ JSON: id, date, message, sender_id

TG Bot Inviter Users — Инвайтер

Что это: Инструмент для массового приглашения пользователей из файла в указанную Telegram-группу или канал. Зачем нужен: Чтобы автоматизировать процесс добавления целевой аудитории в ваш проект — не вручную, а через API. Что получите на выходе: Приглашённые пользователи в группе. Обработка FloodWaitError — инструмент сам ждёт при превышении лимитов.
Telethon: ResolveUsernameRequest — резолв группы, GetParticipantsRequest — проверка членства, InviteToChannelRequest — инвайт
// inviting_process:
1. client.connect(), client.sign_in() — авторизация
2. uname = client(ResolveUsernameRequest(group_username)) — получаем сущность группы
3. target = client.get_entity(uname) — получаем канал
4. existing = client(GetParticipantsRequest(target, ChannelParticipantsSearch(''), 0, 200, hash=0)) — текущие участники
5. Для каждого пользователя из файла:
  user = client.get_entity(user_id)
  client(InviteToChannelRequest(target, [user])) — приглашение
  обработка FloodWaitError — ожидание
