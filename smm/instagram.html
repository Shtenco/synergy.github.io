meta_check

Что это: Проверяет, работает ли ваш Meta/Graph API токен — делает тестовый запрос к API. Зачем нужен: Чтобы убедиться, что токен действителен и у него есть нужные права доступа, прежде чем запускать публикацию. Что получите на выходе: Информацию о токене: срок действия, привязанные страницы и аккаунты, список доступных разрешений.
POST /api/tool — tool: meta_check
Graph API: GET /me — проверка токена
// Параметры
{ "access_token": "EA..." }

post_facebook

Что это: Публикует текстовые посты на стену вашей Facebook Page через Graph API. Зачем нужен: Автоматизирует создание контента — не нужно заходить в Facebook, пост уходит напрямую через API. Что получите на выходе: ID созданного поста, ссылку на него и статус публикации.
POST /api/tool — tool: post_facebook
Graph API: POST /v19.0/{page_id}/feed — создание поста
// Параметры
{ "access_token": "EA...", "page_id": "123456", "text": "Текст поста" }

// Graph API запрос
POST https://graph.facebook.com/v25.0/{page_id}/feed
?message={text}&access_token={token}

post_instagram

Что это: Публикует изображение в Instagram Business Account в два шага: сначала создаёт медиа-контейнер, затем подтверждает публикацию. Зачем нужен: Позволяет выкладывать фото в Instagram автоматически, без ручного ввода — удобно для массового постинга и автоворонок. Что получите на выходе: ID опубликованного поста в Instagram и статус операции.
POST /api/tool — tool: post_instagram
Graph API: POST /{ig_id}/media → POST /{ig_id}/media_publish
// Шаг 1: создание контейнера
POST https://graph.facebook.com/v25.0/{ig_id}/media
?image_url={url}&caption={text}&access_token={token}

// Шаг 2: публикация
POST https://graph.facebook.com/v25.0/{ig_id}/media_publish
?creation_id={id}&access_token={token}
