ok_check

Что это: Инструмент для проверки валидности OK-токена: отправляет тестовый запрос users.getCurrentUser и проверяет, отвечает ли сервер OK данными пользователя. Зачем нужен: Чтобы убедиться, что токен, ключ приложения и секрет работают корректно, перед тем как выполнять публикацию постов или произвольные запросы. Что получите на выходе: JSON-ответ с данными вашего профиля OK (имя, uid, фото) или сообщение об ошибке, если токен недействителен.
POST /api/tool — tool: ok_check
OK API: users.getCurrentUser
// Параметры
{ "access_token": "tkn...", "application_key": "CBA...", "application_secret": "..." }

post_ok

Что это: Инструмент для публикации текстовых постов в Одноклассниках: можно опубликовать запись на своей стене (USER) или в группе (GROUP_THEME с указанием group_id). Зачем нужен: Чтобы автоматически делиться контентом в OK без ручного входа в интерфейс соцсети — полезно для SMM-планирования, кросс-постинга и автопостинга. Что получите на выходе: ID опубликованного топика в OK — его можно сохранить в логах, использовать для решара или просто убедиться, что пост опубликован.
POST /api/tool — tool: post_ok
OK API: mediatopic.post — публикация топика
// Параметры для поста в профиль
{ "text": "Текст поста", "type": "USER" }

// Параметры для поста в группу
{ "text": "Текст", "group_id": "1234567890", "type": "GROUP_THEME" }

ok_api_call

Что это: Универсальный инструмент для выполнения любого метода OK API: вы указываете название метода (например, friends.get) и его параметры, а подпись запроса формируется автоматически. Зачем нужен: Когда нужного инструмента нет в списке — этот метод покрывает все возможности OK API: получение списка друзей, групп, топиков, лайков и других данных. Что получите на выходе: «Сырой» JSON-ответ от сервера OK — все поля, которые возвращает выбранный метод, без ограничений.
POST /api/tool — tool: ok_api_call
OK API: произвольный метод — POST api.ok.ru/fb.do с OK-подписью
// Параметры
{ "method": "users.getCurrentUser", "params": {"fields":"uid,name"} }

// Доступные методы
users.getCurrentUser — данные текущего пользователя
mediatopic.post — публикация топика
mediatopic.getTopics — получение топиков
share.topic — решар топика
friends.get — список друзей
group.getUserGroups — группы пользователя
