VK API

Полный набор методов для работы с ВКонтакте: проверка токена, поиск групп, сбор участников, анализ активности, пересечение аудиторий, рассылка сообщений/комментариев/лайков/приглашений/сторис, очистка стены. vk_api + requests к api.vk.com/method/{method}. Источник: main.py + backend_app.py + TG COMBINE BOT.

vk_check

Что это: Инструмент проверяет, действителен ли ваш VK токен, отправляя запрос к API VK (метод users.get). Зачем нужен: Позволяет убедиться, что токен не просрочен и имеет доступ к аккаунту, прежде чем запускать другие инструменты. Что получите на выходе: JSON с статусом проверки и данными аккаунта (ID, имя, фамилия), если токен валиден.
POST /api/tool — tool: vk_check | VK API: users.get
// Вход
{ "access_token": "vk1.a..." }
// Выход
{ "ok": true, "account": { "id": 12345, "first_name": "Иван" } }

vk_search_groups

Что это: Поиск сообществ ВКонтакте по ключевым словам через методы groups.search и groups.getById. Зачем нужен: Помогает найти релевантные группы для таргетирования, сбора аудитории или анализа конкурентов. Что получите на выходе: Список найденных групп с их ID, названиями, количеством участников и другой информацией.
POST /api/tool — tool: vk_search_groups | groups.search, groups.getById

vk_collect_users

Что это: Сбор списка пользователей из указанных групп ВКонтакте через метод groups.getMembers. Зачем нужен: Необходим для формирования базы участников сообществ для последующего анализа или рассылки. Что получите на выходе: Массив ID пользователей, состоящих в выбранных группах.
POST /api/tool — tool: vk_collect_users | groups.getMembers

vk_activity

Что это: Анализ активности пользователей в группах — сбор лайков, комментариев и репостов через wall.get, likes.getList и wall.getComments. Зачем нужен: Позволяет выявить самых активных участников сообщества для дальнейшего взаимодействия или оценки вовлечённости аудитории. Что получите на выходе: Список пользователей с количеством их лайков, комментариев и репостов, отфильтрованный по заданным критериям.
POST /api/tool — tool: vk_activity | wall.get, likes.getList, wall.getComments
// main.py: vk.wall.get(), vk.likes.getList(), vk.wall.getComments() — фильтр по min_likes, min_comments

vk_audience_intersection

Что это: Поиск пересечений аудиторий между несколькими файлами со списками пользователей. Зачем нужен: Помогает найти пользователей, состоящих в нескольких группах одновременно — это «тёплая» аудитория для таргетированной рассылки. Что получите на выходе: Список пользователей, которые присутствуют одновременно в нескольких загруженных файлах.
POST /api/tool — tool: vk_audience_intersection

vk_mailing

Что это: Многофункциональный инструмент рассылки: отправка сообщений, комментариев, лайков, заявок в друзья, приглашений в группы и просмотр сторис. Зачем нужен: Автоматизирует массовое взаимодействие с аудиторией ВКонтакте для продвижения, привлечения подписчиков и повышения активности. Что получите на выходе: Отчёт о выполненных действиях с указанием статуса каждой операции.
POST /api/tool — tool: vk_mailing
main.py _mailing_process: messages.send, wall.createComment, likes.add, friends.add, stories.get
// main.py полные методы:
vk.messages.getConversations(offset, count) — список диалогов
vk.messages.send(peer_id, message, random_id) — отправка сообщения
vk.wall.get(owner_id, count) — получение постов
vk.wall.createComment(owner_id, post_id, message) — комментарий
vk.likes.add(type, owner_id, item_id) — лайк
vk.friends.add(user_id) — добавление в друзья
vk.stories.get(owner_id) — получение сторис
vk.stories.getById(stories) — получение сторис по идентификатору; реальный просмотр выполняется вручную в VK

SINERGY: Таргетинг ЦА и аналитика

Новый блок инструментов: поиск целевой аудитории по графовым связям (друзья, друзья друзей, подписчики), парсинг по хэштегам и ключевым словам в ленте, поиск заказов/запросов специалистов, отбор лучших групп с открытой стеной для публикации, аналитика собственных постов (лучший час/день, ключевые слова) и работа с беседами ВКонтакте.

vk_friends_graph

Что это: Строит аудиторию по графовым связям: ваши друзья, участники вашего сообщества и (при depth=2) друзья ваших друзей — с подсчётом количества общих связей для каждого кандидата. Зачем нужен: Похожая на вас аудитория чаще всего находится не в случайных группах, а среди друзей ваших друзей и подписчиков смежных сообществ. Что получите на выходе: Ранжированный список кандидатов с числом общих связей, сохранённый в файл для дальнейшего использования (рассылка, приглашение в беседу, пересечение с другой аудиторией).
POST /api/tool — tool: vk_friends_graph | friends.get, groups.getMembers

vk_newsfeed_search

Что это: Поиск публичных постов в открытой ленте ВКонтакте по хэштегу или ключевому слову через официальный метод newsfeed.search. Зачем нужен: Позволяет найти людей, которые уже пишут на нужную тему — готовая тёплая аудитория и материал для контент-исследования. Что получите на выходе: Список найденных постов с авторами и отдельный массив audience_ids — авторов, которых можно использовать как источник для других инструментов (пересечение аудиторий, рассылка).
POST /api/tool — tool: vk_newsfeed_search | newsfeed.search

vk_leads_search

Что это: Поиск заказов и запросов на услуги в открытой ленте и на стенах указанных групп — по фразам вроде «ищу работу», «ищу smm специалиста», «ищем программиста». Встроен набор готовых фраз, можно добавить свои. Зачем нужен: Прямой источник лидов: люди сами пишут о том, что им нужно. Работает только с публичными постами (стены и открытая лента) — доступа к личным сообщениям чужих чатов через API нет и это не реализуется. Что получите на выходе: Список совпадений с категорией (ищет работу / ищет специалиста / заказ), автором, ссылкой на пост и найденной фразой.
POST /api/tool — tool: vk_leads_search | newsfeed.search, wall.get

vk_search_groups_scored

Что это: Поиск групп по ключевым словам с фильтром «открытая стена» (писать может любой пользователь без модерации) и скорингом: количество чужих постов в день делённое на средний охват поста. Зачем нужен: Отбирает группы, где мало конкурирующих постов и высокий охват — лучшие площадки для бесплатного размещения. Чем ниже итоговый score — тем лучше группа. Что получите на выходе: Отсортированный список групп с полями posts_per_day, avg_reach, score, wall_open — готовый список для vk_post_to_groups.
POST /api/tool — tool: vk_search_groups_scored | groups.search, groups.getById, wall.get

vk_post_to_groups

Что это: Публикация одного и того же поста сразу в список групп — например, в лучшие группы с открытой стеной, найденные vk_search_groups_scored. Зачем нужен: Быстрое размещение контента там, где его увидит больше всего людей при наименьшей конкуренции с другими постами. Внимание: публикация в чужие сообщества необратима и должна соответствовать правилам площадки и здравому смыслу — злоупотребление похоже на спам и может привести к бану аккаунта. Что получите на выходе: Отчёт о том, в какие группы пост опубликован успешно, а где произошла ошибка.
POST /api/tool — tool: vk_post_to_groups | wall.post

vk_post_analytics

Что это: Анализ собственной стены (или страницы/сообщества) — какой час дня и день недели дают лучший отклик, и какие слова/хэштеги чаще всего встречаются в самых охватистых и лайкаемых постах. Зачем нужен: Отвечает на вопрос «что лучше всего заходит нашей аудитории» на основе фактических данных, а не догадок. Что получите на выходе: Рейтинг часов и дней недели по среднему вовлечению, а также кластер ключевых слов и хэштегов топ-30% постов по вовлечённости.
POST /api/tool — tool: vk_post_analytics | wall.get

vk_chat_create

Что это: Создание новой беседы ВКонтакте с указанными участниками через messages.createChat. Зачем нужен: Быстрый запуск закрытого или тематического чата — например, для собранной через vk_friends_graph или vk_leads_search аудитории. Что получите на выходе: ID новой беседы и peer_id для дальнейшего использования (в т.ч. в vk_chat_invite).
POST /api/tool — tool: vk_chat_create | messages.createChat

vk_chat_search

Что это: Список собственных бесед ВКонтакте с фильтром по названию через messages.getConversations. VK не предоставляет публичного API для поиска чужих бесед — доступны только те, участником которых является ваш аккаунт. Зачем нужен: Быстро найти нужную беседу (по названию) перед приглашением в неё новых участников через vk_chat_invite. Что получите на выходе: Список бесед с chat_id, peer_id, названием и числом участников.
POST /api/tool — tool: vk_chat_search | messages.getConversations

set_token (автопилот)

Что это: Установка VK токена для работы автопилота. Зачем нужен: Без токена автопилот не сможет выполнять никакие операции в ВКонтакте — это обязательный шаг перед запуском любых инструментов. Что получите на выходе: Подтверждение, что токен сохранён и готов к использованию.
main.py _autopilot_execute_tool("set_token", { "token": "..." })

set_mailing_config (автопилот)

Что это: Настройка параметров автоматической рассылки: источник аудитории, тип действия, фильтры по полу, возрасту, городу и задержки между действиями. Зачем нужен: Позволяет гибко настроить, кому и какие действия выполнять, чтобы рассылка была максимально эффективной и естественной. Что получите на выходе: Сохранённая конфигурация, которая будет использоваться при запуске рассылки.
main.py _autopilot_execute_tool("set_mailing_config", { params })
// Параметры:
source: dialogs|groups|active|common
action: messages|comments|likes|add_friends|add_group|stories|stories_like
gender, age_min, age_max, city, limit, delay_min, delay_max, likes_min, likes_max

set_mailing_messages (автопилот)

Что это: Загрузка списка текстовых сообщений, которые будут использоваться при рассылке. Зачем нужен: Позволяет подготовить несколько вариантов сообщений для ротации, что снижает риск бана и повышает эффективность. Что получите на выходе: Сохранённый список сообщений, готовый к использованию в рассылке.
main.py _autopilot_execute_tool("set_mailing_messages", { "messages": [...] })

start_mailing (автопилот)

Что это: Запуск процесса автоматической рассылки с ранее настроенными параметрами и сообщениями. Зачем нужен: Активирует бота, который начнёт выполнять заданные действия (сообщения, лайки, комментарии и т.д.) по расписанию. Что получите на выходе: Лог выполнения с информацией о каждом отправленном действии.
main.py _autopilot_execute_tool("start_mailing", {})

search_groups (автопилот)

Что это: Поиск групп ВКонтакте с расширенными параметрами фильтрации через _groups_process. Зачем нужен: Позволяет найти максимально релевантные сообщества по ключевым словам с учётом минимального количества участников. Что получите на выходе: Список подходящих групп, сохранённый в файл для дальнейшего использования.
main.py _autopilot_execute_tool("search_groups", {...}) | groups.search, groups.getById

analyze_activity (автопилот)

Что это: Анализ активности пользователей в группах с фильтрацией по минимальному количеству лайков и комментариев. Зачем нужен: Помогает отсеять пассивных участников и найти наиболее вовлечённых пользователей для целевого взаимодействия. Что получите на выходе: Отфильтрованный список активных пользователей с детализацией по каждому типу активности.
main.py _autopilot_execute_tool("analyze_activity", {...})

find_audience_intersection (автопилот)

Что это: Поиск пересечений аудиторий между несколькими группами через groups.getMembers. Зачем нужен: Выявляет пользователей, состоящих одновременно в нескольких группах — это наиболее ценная аудитория для рассылки. Что получите на выходе: Список пользователей, входящих в указанное количество групп и более.
main.py _autopilot_execute_tool("find_audience_intersection", {...})

clean_wall

Что это: Полная очистка стены указанной группы ВКонтакте через методы wall.get и wall.delete. Зачем нужен: Полезно при необходимости удалить все посты со стены сообщества — например, перед ребрендингом или сменой концепции. Что получите на выходе: Подтверждение удаления каждого поста. Внимание: действие необратимо!
POST /api/tool — tool: clean_wall | wall.get, wall.delete
main.py _autopilot_execute_tool("clean_wall", {...})
