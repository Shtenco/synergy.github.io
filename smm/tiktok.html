TikTok API

Официальный Content Posting API для публикации видео. Требует прохождения аудита TikTok — до аудита видео публикуются приватно.

О TikTok Content Posting API

Важно: TikTok требует прохождения аудита приложения. До аудита все загруженные видео будут приватными (SELF_ONLY). Аудит занимает 2-4 недели.
Что возможно через API:
  • Загрузка видео (chunked upload)
  • Публикация фото-каруселей
  • Получение информации о Creator
  • Просмотр своих видео и статистики
  • Проверка статуса публикации

Ограничения:
  • 25 видео в день на аккаунт
  • 6 запросов в минуту на upload endpoint
  • Бизнес-аккаунты теряют доступ к коммерческой музыке
  • Нет API для комментариев и лайков (запрещено)

Подключение TikTok

Сохраните access_token, полученный через OAuth TikTok Login Kit.
Как получить токен: Создайте приложение на developers.tiktok.com, настройте OAuth, получите access_token через авторизацию пользователя.
POST /api/tool — tool: tiktok_save_token
POST /api/tool — tool: tiktok_check

Информация о Creator

Получить информацию о возможностях публикации: duet, stitch, комментарии и т.д.
POST /api/tool — tool: tiktok_creator_info

Загрузка видео

Инициализация загрузки видео. После инициализации вы получите upload_url для загрузки файла и publish_id для проверки статуса.
Privacy levels: SELF_ONLY (приватно), MUTUAL_FOLLOW_FRIENDS (друзья), FOLLOWER_OF_CREATOR (подписчики), PUBLIC_TO_EVERYONE (все)
POST /api/tool — tool: tiktok_init_video_upload
Отключить Duet
Отключить Stitch
Отключить комментарии

Статус публикации

Проверить статус загрузки/публикации видео по publish_id.
POST /api/tool — tool: tiktok_post_status

Мои видео

Получить список своих видео со статистикой просмотров, лайков, комментариев.
POST /api/tool — tool: tiktok_query_videos
