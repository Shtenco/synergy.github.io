О Signal и автоматизации

Важно: Signal не предоставляет официальный Bot API в целях приватности. Автоматизация возможна только через signal-cli — консольный клиент, который нужно запустить на своём сервере. Это требует технической настройки.
Что возможно:
  • Отправка и получение сообщений
  • Управление группами
  • Отправка вложений (фото, файлы)
  • Реакции на сообщения
  • Интеграция с автоматизацией (Home Assistant, n8n, etc.)

Настройка signal-cli-rest-api

Требуется: Docker на вашем сервере. Запустите контейнер с signal-cli-rest-api, затем зарегистрируйте или привяжите номер телефона.
Docker запуск:
docker run -d --name signal-api -p 8080:8080 -v signal-data:/home/.local/share/signal-cli bbernhard/signal-cli-rest-api

Привязка как вторичное устройство:
Откройте http://your-server:8080/v1/qrcodelink?device_name=sinergy-smm и отсканируйте QR в Signal на телефоне.

Подключение к Signal API

Укажите URL вашего signal-cli-rest-api сервера и номер телефона, привязанный к Signal.
POST /api/tool — tool: signal_save_config
POST /api/tool — tool: signal_check

Отправка сообщений

Отправка сообщения одному или нескольким получателям. Получатели — номера телефонов в формате +79991234567.
POST /api/tool — tool: signal_send_message
Период охлаждения: номера, которым уже отправляли сообщение, автоматически пропускаются. Срок задаётся в основном кабинете → «Защита от повторов» → Signal.

Получение сообщений

Получить новые входящие сообщения. Signal не поддерживает webhooks, поэтому нужно периодически запрашивать обновления.
POST /api/tool — tool: signal_receive

Группы Signal

Получить список групп, в которых вы состоите.
POST /api/tool — tool: signal_groups

Контакты / Identities

POST /api/tool — tool: signal_identities
