SYNERGY / FIRST RUN / VERIFIED MODE

Один проект.
Два режима открытия.

01 · Дизайн без сервера

Откройте public/portal/index.html или public/smm/workspaces.html непосредственно с диска. Стили и навигация должны загружаться через относительные пути. Авторизация и данные не будут доступны.

Просмотреть портал ↗Открыть SMM ↗

02 · Рабочий сайт с Python API

Из корня распакованного проекта установите зависимости и запустите сервер. Вторая консоль используется для фонового worker при необходимости.

py -m pip install -r requirements.txt
set ADMIN_PASSWORD=ВАШ_ПАРОЛЬ
set SESSION_SECRET=СЛУЧАЙНАЯ_СТРОКА_НЕ_МЕНЕЕ_32_СИМВОЛОВ
py -m uvicorn app.main:app --host 127.0.0.1 --port 8080

PowerShell: задавайте переменные через $env:ADMIN_PASSWORD="..." и $env:SESSION_SECRET="...". Адрес: http://127.0.0.1:8080/portal/.

03 · Почему пусто?

На 8 защищённых страницах данные и рабочие формы могут скрываться до входа в CaseFlow Team. Доступ определяется ролью и организацией. На локальном предпросмотре это не поломка CSS, а отсутствие серверной сессии. Живые VK/Telegram и Gemini требуют отдельной авторизованной интеграции.
